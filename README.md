# layla_hackathon

Mobile-first Next.js web app (see `claude.md` for the product overview).

## Getting started

```bash
npm install
cp .env.example .env.local   # fill in secrets
npm run dev                  # http://localhost:3000
```

Open it in a phone browser (same Wi‑Fi: `http://<your-ip>:3000`) or use the mobile emulator in browser devtools.

## Stack

- Next.js (App Router, TypeScript, `src/` dir)
- Tailwind CSS v4
